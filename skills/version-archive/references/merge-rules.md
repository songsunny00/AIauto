# 各文档增量合并规则

增量合并模式下，各文档的具体合并方式。

## 01-需求文档.md 合并

1. **功能清单表**：新增→插入行；修改→替换同编号行；删除→移除行
2. **REQ 详情区块**（按 `#### REQ-xxx` 标题定位）：新增→插入到对应模块区块末尾；修改→替换区块内容；删除→移除整个区块
3. **验收标准表**（按验收点编号去重）：新增/修改→增量覆盖同编号行；删除→移除关联该 REQ 的验收点行
4. **追踪矩阵**：同功能清单表逻辑
5. **非 REQ 区块内容**：保留基线版本，不合并

## 02-详细设计文档.md 合并

1. **需求实现清单表**：同 01 功能清单表逻辑
2. **REQ 详情区块**（按 `##### REQ-xxx` 标题定位）：同 01 详情区块逻辑
3. **接口清单表**（按接口路径去重）：
   - 新增/修改→增量覆盖同路径行
   - 删除→从"关联需求编号"列解析该接口关联的所有 REQ，若该列中除被删除 REQ 外还包含其他未删除的 REQ，仅从该列移除被删除的 REQ 编号；若所有 REQ 均已被删除，则移除该接口行
4. **非 REQ 区块内容**：保留基线版本

## 03-测试用例文档.md 合并

1. **用例表**（按测试编号处理）：
   - 新增/修改→增量覆盖同编号行
   - 删除→移除关联被删除 REQ 的所有测试用例行
2. **非用例区块内容**：保留基线版本

## 合并后的区块排序

- REQ 详情区块按 REQ 编号自然序排列（LIST-001, LIST-002, LIST-003, FORM-001, FORM-002, DETAIL-001）
- 测试用例按测试编号自然序排列

## 删除操作的连带处理

删除一个 REQ 时，需要连带处理：
- 01：功能清单表行 + 详情区块 + 验收标准表行 + 追踪矩阵行
- 02：需求实现清单表行 + 详情区块 + 接口清单表行（从"关联需求编号"列解析，若该接口仍被其他未删除 REQ 引用则仅移除该 REQ 编号，否则移除整行）
- 03：关联该 REQ 的所有测试用例行

输出删除清单，在合并预览中明确展示"将删除 REQ-xxx 及其关联的 {N} 条测试用例、{M} 个验收点"，经用户确认后执行。

## 合并冲突处理

| 场景 | 处理 |
|---|---|
| 增量文档中某 REQ 区块无法定位到完整边界 | 阻断，输出"REQ-xxx 区块边界无法识别，请检查文档格式" |
| 基线文档中某 REQ 区块格式异常 | 阻断，输出"基线文档中 REQ-xxx 区块格式异常，建议使用 --full 全量覆盖重置基线" |
| 删除 REQ 时基线中关联的测试用例/验收点无法定位 | 阻断，输出"REQ-xxx 删除时无法定位关联的 {测试用例/验收点}，请检查基线文档完整性" |
