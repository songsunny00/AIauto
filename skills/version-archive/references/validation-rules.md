# 一致性校验规则

校验在回写前执行，任一失败即停止。校验按模块分别执行。

## 校验项

| 校验项 | 规则 | 失败处理 |
|---|---|---|
| REQ 编号格式 | 匹配 `REQ-{L1}-{L2}-{L3}-{NNN}` | 阻断，输出不合规编号清单 |
| REQ 操作类型 | 01 REQ 清单表中已有「需求类型」列，值为 新增/修改/删除 之一 | 阻断，输出缺失或非法需求类型的 REQ 清单 |
| 需求类型一致性 | 01 REQ 清单表中的需求类型与 REQ 详情区块元信息表中的需求类型一致 | 阻断，输出不一致的 REQ 清单 |
| REQ 在 02 有对应 | 01 中操作类型为新增/修改的每个 REQ 在 02 详设中能找到引用 | 阻断，输出缺失清单 |
| REQ 在 03 有对应 | 01 中操作类型为新增/修改的每个 REQ 在 03 用例中能找到覆盖 | 阻断，输出未覆盖清单 |
| 测试编号格式 | 匹配 `FT/IT/PT/ET-{L1}-{L2}-{功能域}-{NNN}` | 阻断，输出不合规编号清单 |

## 删除操作的校验豁免

操作类型为"删除"的 REQ 不校验 02/03 对应。但需校验该 REQ 在对应模块的基线 01 中确实存在，否则提示"REQ-xxx 标记为删除但基线中不存在，请确认"。

## 校验方式

文本检索（grep 风格），不要求语义理解。只要编号字符串在目标文档中出现即视为"有对应"。
