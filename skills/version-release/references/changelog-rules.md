# CHANGELOG 收敛规则

## 固定表头

`Prds/CHANGELOG.md` 只记录已经封版的版本，不记录需求变更过程。文件必须使用现行固定表头，列名和顺序均不得变更：

```text
版本号 | 变更日期 | 变更类型 | 影响模块 | 主需求文档 | 详细变更记录 | 主文档回写状态 | 测试状态 | 发布状态 | 备注
```

## 解析规则

- 第一列 `版本号` 必须是规范化版本号的精确匹配，不按前缀、模糊文本或备注内容匹配；
- `发布状态` 列必须存在且为单元格文本的精确值。

## 普通封版清理规则

1. 只处理第一列与目标版本号完全相等的记录；
2. 目标版本记录中，`发布状态` 不等于 `已封版` 的记录视为过程性记录并删除；
3. 目标版本记录中，`发布状态=已封版` 的记录视为已封版冲突，普通模式停止；
4. 目标版本存在重复的最终记录、缺少必需列、列数不一致或无法解析的行时停止，不尝试猜测或重排；
5. 保留其他版本的记录，不在本次封版中迁移或清理历史台账；
6. 写入目标版本唯一的一条最终封版记录；
7. 需求变更过程继续保留在版本目录下的 `05-变更记录.md`。

如果目标版本已经存在带目标 Tag 名的记录，普通模式同样停止。

## 最终封版记录取值规则

| 列 | 取值 |
|---|---|
| 版本号 | 规范化版本号（如 V1.6.1） |
| 变更日期 | 封版执行日期，格式 `YYYY-MM-DD` |
| 变更类型 | 来自版本 `01`/`05` |
| 影响模块 | 来自版本 `01`/`05` |
| 主需求文档 | 来自版本 `01`/`05` |
| 详细变更记录 | 来自版本 `01`/`05` |
| 主文档回写状态 | `已回写`（封版门禁已校验归档完成） |
| 测试状态 | 版本测试报告中的最终测试结论（如 `已通过` / `有条件通过`，从 `04-测试报告文档.md` 提取） |
| 发布状态 | `已封版` |
| 备注 | 包含目标 Tag 名（如 `Tag-V1.6.1`） |
