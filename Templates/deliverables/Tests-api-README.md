# API 自动化目录说明模板

## 0. 使用说明

- **定位**：用于模块级 `Tests/api/.../README.md`。
- **适用场景**：说明当前目录覆盖范围、接口依赖、环境、鉴权、数据依赖和执行方式。
- **输出路径**：例如 `Tests/api/CONFIG-配置中心/REPORTCFG-报告配置/TYPECFG-报告类别配置/README.md`。
