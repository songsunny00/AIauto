## 二、技术方案

### 2.1 测试工具链

| 层次 | 工具 | 用途 |
| --- | --- | --- |
| 浏览器自动化 | `playwright-cli`（基于 Playwright） | 驱动 MS Edge 浏览器执行页面交互 |
| 认证态复用 | `storageState`（`.auth/*.json`） | 通过登录后保存 cookie + localStorage，后续操作免登录 |
| 批量操作 | `run-code "async page => { ... }"` | 在单次调用中执行多步骤交互并返回结构化 JSON |
| 元素定位 | `getByRole` / `getByTestId` / CSS 选择器 | 优先语义化定位，组件库 class 兜底 |
| 截图归档 | `screenshot --filename=...` | 关键步骤截图保存至 `testing-imgs/` |

### 2.2 测试策略

1. **认证态复用**：{{登录策略说明}}
2. **前置数据探测**：测试前使用 `run-code` 采集页面数据分布（总行数、状态分布、关键字段值），判断用例前置条件是否满足。
3. **只读优先**：先执行不改变数据的用例，后执行写操作用例，新增数据复用给编辑/删除。
4. **批量验证**：对同类操作使用 `run-code` 循环执行。
5. **文案精确比对**：校验类用例逐字比对实际提示与预期文案。
6. **截图留证**：每个用例执行完毕后截图（成功和失败均截），命名带 `SUCCESS`/`FAIL` 标识。
