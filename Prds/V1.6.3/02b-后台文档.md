## 1. 变动总览

| 类别 | 内容 | 影响接口 |
|---|---|---|
| **新增接口** | 租户配额分页、租户全量汇总、租户授权启停、分析套餐下拉、存储资源分页、下载记录分页 | 6 个，见 §3 |
| **请求体变更** | 合同 add/edit 新增增值存储 4 字段；配额行新增 `analysisPackageCode`（必填）；`startDate`/`endDate`/`sampleTotalQuota` 不再是 DTO 层硬必填 | `POST /base/quota/contract/add`、`/edit` |
| **响应体变更** | 合同 page/detail 透出存储 4 字段；配额行透出 `analysisPackageCode`；`displayStatus` 枚举扩为 5 态 | `/page`、`/{contractId}`、租户 `/page` |
| **响应体变更** | 合同变更日志新增 `changeType`/`changeTypeDesc` | `POST /base/quota/usage/history` |
| **新错误码** | `10022010` 分析套餐重复、`10022011` 租户已禁用授权 | 见 §6 |

**兼容性**：所有请求体变更为**新增可选字段**，旧报文不会报错（除配额行的 `analysisPackageCode`——v1.6.3.1 起新建/编辑合同若提交配额行，该字段必填）。响应体只加字段不改字段，前端旧页面可渐进式适配。

## 2. 通用约定

- **响应信封**：所有接口统一返回

```json
{
  "requestId": "trace-id",
  "retCode": 0,          // 0=成功，非 0 见 §6 错误码
  "retInfo": "success",
  "result": { ... }      // 业务数据，失败时可能为 null
}
```

- **时间格式**：入参、出参统一 `yyyy-MM-dd HH:mm:ss`（GMT+8，精确到秒）。datetime 选择器必须带时分秒，纯日期字符串会反序列化失败。
- **鉴权**：登录后带 `omics-vtk: {{token}}` 请求头（与既有接口一致）。
- **权限点**：本期新增接口的 `@OperationPermissions` 均为注释状态（权限点待权限中台登记），联调阶段不会 403。

## 3. 新增接口

### 3.1 分析套餐下拉

`GET /base/quota/contract/analysis-packages`

合同配额行「分析套餐」下拉的数据源。仅返回启用项（`del_flag=0 AND status='ENABLED'`），按 `packageCode` 升序。

**返回** `result: AnalysisPackageOptionVO[]`：

| 字段 | 类型 | 说明 |
|---|---|---|
| packageCode | String | 套餐编码（`SDxxxx`，下拉 value） |
| packageName | String | 套餐名称（下拉 label） |
| projectCode | String | 所属检测项目编码；**存储类套餐为 null** |

### 3.2 存储资源分页（一行一条云备份任务）

`POST /base/quota/usage/storage/page`

增值存储用量明细分页。每行对应一个云备份任务，按 `backupTime` 倒序排列，排除备份状态为 `FAILED` 的任务。

**筛选条件**：

| 字段 | 类型 | 说明 |
|---|---|---|
| fileName | String | 文件名模糊匹配 |
| contractNo | String | 合同编号模糊匹配 |
| backupTime | Date | 备份时间范围筛选 |
| instCode | String | 机构编码，可选 |

分页参数 `pageNum`/`pageSize` 按通用分页约定传入。

### 3.3 下载记录分页（文件聚合）

`POST /base/quota/usage/download/page`

下载记录分页，按 `instCode + module + fileId` 聚合为文件级记录；排除状态为 `FAILED` 的下载记录。

**核心返回字段**：

| 字段 | 类型 | 说明 |
|---|---|---|
| usedCount | Integer | 已使用下载次数，恒按全量历史口径统计；时间筛选仅过滤返回行，不改变该字段的统计范围 |
| downloadLimit | Integer | 单文件下载次数上限 |
| remainCount | Integer | 剩余下载次数 |
| downloader | String | 下载端：`BROWSER` / `CLIENT` |
| lastDownloadTime | Date | 最近一次下载时间 |
| lastOperatorName | String | 最近一次操作人名称 |
| fileCreateTime | Date | 文件创建时间 |

分页参数 `pageNum`/`pageSize` 按通用分页约定传入。

### 3.4 租户配额分页（一行一租户，多合同聚合）

`POST /base/quota/tenant/page`

**入参** `QuotaTenantQO`（`pageNum`/`pageSize` 必填，其余可选）：

| 字段 | 类型 | 说明 |
|---|---|---|
| instCode | String | 机构编码，**多选逗号分隔**（如 `INST00001,INST00002`），后端走 IN |
| instName | String | 机构名称，模糊匹配 |
| analysisPackageCode | String | 分析套餐编码，多选逗号分隔；命中任一套餐即返回该租户 |
| projectCode | String | 检测项目编码，多选逗号分隔 |
| productNo | String | 产品套餐编号，多选逗号分隔 |
| displayStatus | String | 合同展示状态筛选（5 态枚举见 §5.1）；租户名下**任一合同**命中即返回 |
| authStatus | String | 租户授权状态：`ENABLED`（含无授权记录的租户）/ `DISABLED` |

> 覆盖范围三项（analysisPackageCode/projectCode/productNo）是「合同→配额行→覆盖明细」三级关联属性，按租户维度聚合过滤，与合同列表的同名筛选项口径一致但粒度是租户。

**返回** `result: Page<QuotaTenantVO>`，每行：

| 字段 | 类型 | 聚合口径 | 说明 |
|---|---|---|---|
| instCode / instName | String | — | 租户编号 / 机构名称（机构表权威回填） |
| contractCount | Integer | 所有有效合同 | 合同数量（主列「合同编号」位置展示） |
| analysisPackages | String | 当前生效合同 | 分析套餐去重合并，逗号分隔 |
| projectCodes | String | 当前生效合同 | 检测项目去重合并，逗号分隔 |
| sampleTotalQuotaSum | Integer | 当前生效合同 | 样本分析总次数 Σsample_total_quota |
| storageDaysMax | Integer | 当前生效合同 | 免费存储期限(天) MAX |
| downloadLimitMax | Integer | 当前生效合同 | 单样本下载次数 MAX |
| normalCount | Integer | 所有有效合同 | 状态计数，**计数>0 才返回**，前端拼「正常×2 即将到期×1」 |
| expiringSoonCount | Integer | 同上 | |
| expiredCount | Integer | 同上 | |
| disabledCount | Integer | 同上 | |
| upcomingCount | Integer | 同上 | 即将生效（本期新增） |
| authStatus | String | — | `ENABLED`/`DISABLED`；无授权记录视为 ENABLED |
| contracts | ContractBriefVO[] | 所有有效合同 | hover 浮层明细 |

`ContractBriefVO`：`contractNo`（合同编号）、`startDate`、`endDate`（`yyyy-MM-dd HH:mm:ss`）、`displayStatus`（5 态枚举）。

> 两个聚合口径：**数值类字段**（套餐/项目/次数/期限/下载）仅基于「当前生效合同」（status=ENABLED 且 start≤now≤end）；**五态计数与 hover 明细**覆盖「所有有效合同」。列展示用前者，全景徽标用后者。

### 3.5 租户全量汇总（单租户总览）

`POST /base/quota/tenant/summary`

**入参** `QuotaTenantSummaryQO`：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| instCode | String | 是 | 机构编码（`@NotBlank`，空值直接校验失败） |

**返回** `result: QuotaTenantSummaryVO`：

| 字段 | 类型 | 说明 |
|---|---|---|
| instCode / instName | String | 回显；机构名称机构表权威回填，未命中回退合同冗余名 |
| authStatus | String | `ENABLED`/`DISABLED`（无记录=ENABLED） |
| contractCount | Integer | **当前生效合同数**（过期/停用/终止/待生效不计数）⚠️ 与 page 的「所有有效合同」口径不同 |
| totalQuota | Integer | 总配额＝生效合同所有配额行 Σsample_quota（行级） |
| usedCount | Integer | 已消耗 Σ(used_count+frozen_count)，**含预扣冻结** ⚠️ 与用量汇总接口的「仅已确认」口径不同 |
| remainCount | Integer | 剩余次数 = totalQuota − usedCount |
| storageDays | Integer | 免费存储期限(天)，生效合同 MAX(storage_days) |
| storageCapacityTb | Integer | 增值存储容量(TB)，仅 storage_enabled=1 的生效合同 MAX；未开通为 null |
| storageUsedTb | Integer | **本期恒为 null（预留字段），前端不要依赖** |
| storageEndDate | Date | 增值存储到期日，仅开通存储的生效合同 MAX；未开通为 null |
| downloadLimit | Integer | 单样本下载次数，生效合同 MAX |

无生效合同时数值字段返回 0（非 null），可直接展示。

### 3.6 租户授权启停

`POST /base/quota/tenant/toggle/{instCode}/{authStatus}`

路径变量：`instCode` 机构编码；`authStatus` 仅允许 `ENABLED` | `DISABLED`（其他值报「授权状态只能为 ENABLED/DISABLED」）。返回 `result: Boolean`。

**禁用语义**（重要，前端确认弹窗文案可用）：
- 禁用后该租户**所有合同不生效**：样本分析预扣（reserve）入口运行时拦截，抛 `10022011`（§6）；
- **不改合同 status**、不影响已预扣任务的 confirm/refund；重新启用后立即恢复可用；
- 与机构启停（base_auth_institution.status）独立，互不联动；
- 无授权记录的租户默认即 ENABLED；首次禁用才落库。

## 4. 既有接口变更

### 4.1 合同新增/编辑：`POST /base/quota/contract/add`、`/edit`

请求体 `QuotaContractDTO` **新增字段**（顶层，增值存储配置）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| storageEnabled | Boolean | 见下 | 是否开通增值存储；null/false=未开通 |
| storageCapacityTb | Integer | storageEnabled=true 时必填 | 增值存储容量(TB)，≥1 正整数 |
| storageStartDate | Date | storageEnabled=true 时必填 | 增值存储生效日，`yyyy-MM-dd HH:mm:ss` |
| storageEndDate | Date | storageEnabled=true 时必填 | 增值存储截止日，同上，不得早于生效日 |

配额行 `lines[]` **新增字段**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| analysisPackageCode | String | **是**（`@NotEmpty`，lines 非空时每个元素必填） | 分析套餐编码（§3.1 下拉的 value）；**同一合同内不可重复**，且必须存在于启用套餐字典 |

**必填性变化（表单逻辑需配合）**：`startDate`/`endDate`/`sampleTotalQuota` 从 DTO 层硬必填下沉到 business 层按「合同模式」判定：

| 模式 | 判定（后端按入参自判） | 校验 |
|---|---|---|
| SAMPLE 样本配额合同 | `sampleTotalQuota>0` 或 `lines` 非空 | 生效日/截止日必填、sampleTotalQuota 必填正整数、行配额之和 ≤ 总配额、覆盖不重复、分析套餐有效 |
| STORAGE_ONLY 纯存储合同 | 无样本配额（不传 sampleTotalQuota/lines） | 免除样本配额类校验，但**必须开通增值存储**（否则报「纯存储合同必须开通增值存储」） |

即：本期支持**只签增值存储、不买样本配额**的合同。前端表单建议做成「样本配额」与「增值存储」两段可独立配置，纯存储提交时不传 `startDate`/`endDate`/`sampleTotalQuota`/`lines`。

**编辑场景的存储约束**（后端强校验，前端表单需禁用相应控件）：
- 存储开关**一次性配置**：开通后不可关闭，未开通不可开通（编辑报「存储开关不可修改」）；
- 存储**起止时间不可修改**（调整应走续约/新建合同）；**容量可调整**（扩容/缩容）。

**新建场景的跨合同校验**：开通增值存储时，同机构下新合同的存储服务周期不得与任一既有存储合同周期重叠（首尾相接允许背靠背），违例报「当前机构已有有效存储服务，新的存储服务周期与现有服务周期存在重叠，请调整服务开始时间」。

### 4.2 合同分页/详情：`POST /base/quota/contract/page`、`GET /base/quota/contract/{contractId}`

返回 `QuotaContractVO` **新增字段**（与入参同名同义）：`storageEnabled`、`storageCapacityTb`、`storageStartDate`、`storageEndDate`（日期 `yyyy-MM-dd HH:mm:ss`）。

返回 `lines[]`（`QuotaLineVO`）**新增字段**：`analysisPackageCode`（分析套餐编码，编辑回显时回填到行表单）。

`displayStatus` **枚举扩为 5 态**（原 4 态），前端徽标映射需补一档，详见 §5.1。

分页查询入参 `QuotaContractQO.displayStatus` 同步支持 `UPCOMING` 筛选。

### 4.3 合同变更历史：`POST /base/quota/usage/history`

返回 `QuotaContractChangeLogVO` **新增字段**：

| 字段 | 类型 | 说明 |
|---|---|---|
| changeType | String | 变更类型：`QUOTA_ADJUST` 配额调整 / `STORAGE_ADJUST` 存储调整 / `DOWNLOAD_ADJUST` 下载次数调整。与 opType（CREATE/EDIT 动作）正交，描述本次动的是哪一类配额。**历史数据无此列为 null** |
| changeTypeDesc | String | 变更类型中文描述（后端反查枚举补齐），changeType 为空或未命中时 null |

快照字段 `snapshotBefore`/`snapshotAfter`（JSON 文本）中本期起会包含增值存储字段，前端 diff 渲染需兼容新 key：`storageEnabled`/`storageCapacityTb`/`storageStartDate`/`storageEndDate`。

## 5. 枚举字典

### 5.1 合同展示状态 displayStatus（新增 UPCOMING，共 5 态）

查询时派生，不落库；颜色前端按 code 自渲染。优先级从高到低：

| code | 含义 | 派生条件 |
|---|---|---|
| DISABLED | 已停用 | 落库 status=DISABLED 或 TERMINATED（终止并入已停用） |
| UPCOMING | **即将生效（新增）** | 启用且开始时间严格晚于当前时刻 |
| EXPIRED | 已到期 | 启用（已生效）且已过到期日 |
| EXPIRING_SOON | 即将到期 | 启用（已生效）且剩余到期 ≤ 30 天 |
| NORMAL | 正常 | 启用（已生效）且剩余到期 > 30 天 |

适用位置：合同 page/detail 的 `displayStatus`、租户 page 的 `contracts[].displayStatus`、两处分页 QO 的 `displayStatus` 筛选值、租户 page 的 `upcomingCount`。

### 5.2 租户授权状态 authStatus

`ENABLED` 启用（含无授权记录）/ `DISABLED` 禁用。

### 5.3 合同变更类型 changeType

`QUOTA_ADJUST` / `STORAGE_ADJUST` / `DOWNLOAD_ADJUST`，可能为 null（历史数据）。

## 6. 错误码（本期新增）

| retCode | 枚举 | 文案 | 触发场景 |
|---|---|---|---|
| 10022010 | QUOTA_PACKAGE_DUPLICATE | 同一合同内分析套餐不可重复 | add/edit 提交的 lines 中 analysisPackageCode 重复 |
| 10022011 | QUOTA_TENANT_DISABLED | 租户已被禁用授权，所有合同暂不生效 | 已禁用租户的样本提交/预扣（reserve）时拦截（编号为占位，最终以号段负责人确认为准） |

复用既有错误码、但文案为本期新增场景的（前端按 retInfo 提示即可）：`10022003` 参数错误（存储容量/日期缺失、纯存储合同未开通存储、存储开关或起止时间被修改、分析套餐不在启用字典、租户 toggle 传非法 authStatus 等）；`10022007` 合同日期非法（存储生效晚于到期）。

## 7. 联调指引

现成请求样例（IntelliJ HTTP Client，登录 token 自动透传）见 http-request 仓库：

- `omics-base/local/quota/quota-contract.http` —— 合同 page/detail/add/edit/toggle
- `omics-base/local/quota/quota-tenant.http` —— 租户 page/summary/toggle（含多选筛选组合样例）
- `omics-base/local/quota/quota-contract-storage-flow.http` —— 增值存储端到端场景（新建纯存储合同 → 扩容 → 改开关被拒 → 改周期被拒 → 查 STORAGE_ADJUST 流水）

建议联调场景清单：

1. 分析套餐下拉加载 → 新建含配额行合同（行选套餐）→ page/detail 回显 `analysisPackageCode`；
2. 行内套餐重复提交 → 期望 10022010；
3. 新建纯存储合同（不传 startDate/endDate/sampleTotalQuota/lines，storageEnabled=true）→ 成功；漏开存储开关 → 期望参数错误；
4. 编辑纯存储合同：仅改 storageCapacityTb → 成功；改开关/起止时间 → 期望参数错误；
5. 同机构第二份存储合同周期与第一份重叠 → 期望参数错误；首尾相接（背靠背）→ 成功；
6. 建一份 startDate 在未来的合同 → page 与租户 page 出现 UPCOMING 徽标/upcomingCount；
7. 租户 page 各筛选组合（多选机构/套餐/项目/产品、displayStatus、authStatus）；
8. 租户 summary 单租户总览（对照 page 数值口径差异）；
9. 租户 toggle 禁用 → 该租户提交样本分析 → 期望 10022011；toggle 启用后恢复；
10. usage/history 展示 changeType/changeTypeDesc 与存储字段快照 diff。
