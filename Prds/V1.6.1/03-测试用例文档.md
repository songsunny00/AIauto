# V1.6.1 测试用例文档（配置中心-商业化计费配置）

## 1. 测试范围

### 1.1 测试目标

本轮测试面向 `配置中心 / 商业化计费配置` 模块，验证合同分页查询、合同维度与套餐维度展示、新增、编辑、启用/禁用、明细抽屉查看等能力是否与 `01-需求文档.md`、`02-详细设计文档.md`、`02b-后台文档.md` 保持一致，并覆盖功能路径、接口路径、权限路径、异常路径四类核心场景。

### 1.2 范围模块

| 模块编号 | 模块名                    | 覆盖深度 |
| -------- | ------------------------- | -------- |
| 4.1      | 配置中心 / 商业化计费配置 | 全量     |

### 1.3 本轮不测项

| 类型       | 不测项                                             | 原因                                                      |
| ---------- | -------------------------------------------------- | --------------------------------------------------------- |
| 后台接口   | `POST /base/quota/usage/summary`                   | `01/02` 未纳入当前页面链路                                |
| 后台接口   | `POST /base/quota/usage/export`                    | `01/02` 未纳入当前页面链路                                |
| 后台接口   | `GET /base/quota/contract/coverage-candidates`     | 当前前端实现未直连该接口，仍通过项目/产品接口组装级联选项 |
| 后台接口   | `POST /base/quota/contract/terminate/{contractId}` | 当前前端无“终止合同”入口                                  |
| 服务间接口 | `/openapi/quota/v1/*`、`/exchange/quota/v1/remain` | 不属于后台管理页面测试范围                                |
| 业务能力   | 租户侧自助购买、支付、对账                         | `01-需求文档.md` 明确不在本期范围                         |
| 业务能力   | 批量启用/禁用、批量删除                            | `01-需求文档.md` 明确不在本期范围                         |

## 2. 测试环境与数据准备

### 2.1 环境信息

| 项       | 内容                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| 环境名   | test / 联调环境                                                                  |
| 前端入口 | 配置中心 / 商业化计费配置页面                                                    |
| 后端入口 | `omics-gateway` 转发 `omics-core` 的后台管理接口                                 |
| 鉴权方式 | 登录用户 token                                                                   |
| 数据要求 | 前后端需指向同一套联调数据；合同、机构、项目、产品、消耗记录、变更日志均需可查询 |

### 2.2 测试账号矩阵

| 账号类型                                          | 使用场景                              | 预期权限                                                                             |
| ------------------------------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------ |
| `admin` 角色账号（菜单权限包含 `menuId=11013`）   | 页面功能全链路、UI 回归、正向接口联调 | 可进入页面，可执行查询、新增、编辑、明细、启用、禁用                                 |
| `admin` 角色账号（菜单权限不包含 `menuId=11013`） | 页面权限校验                          | 不可进入该菜单页面                                                                   |
| 任意有效登录用户                                  | API 鉴权现状校验                      | 由于 `@OperationPermissions` 当前未启用，持有效 token 时接口不应因按钮权限缺失被拒绝 |
| 未登录态                                          | 路由与接口未登录校验                  | 页面应跳登录；接口应返回未登录/401                                                   |

### 2.3 数据初始化要求

执行本测试集前，至少准备以下测试数据：

1. **机构候选数据**：至少 2 个启用机构，用于查询筛选与新增弹窗机构下拉。
2. **项目 / 产品套餐候选数据**：至少 2 个检测项目；每个项目至少 1 个产品套餐，用于级联多选。
3. **合同状态数据**：
   - 1 条 正常（`NORMAL`）合同；
   - 1 条 即将到期（`EXPIRING_SOON`）合同；
   - 1 条 已到期（`EXPIRED`）合同；
   - 1 条 已停用（`DISABLED`）合同。
4. **编辑态数据**：
   - 1 条未产生样本分析消耗（消耗次数为 0）的合同，用于可编辑场景；
   - 1 条已产生样本分析消耗（消耗次数大于 0）的合同，用于只读场景。
5. **用量与历史数据**：
   - 1 条存在已确认消耗记录的合同；
   - 1 条仅有新增历史、无编辑历史的合同；
   - 1 条存在至少 1 次编辑记录的合同。
6. **边界校验数据**：
   - 同一机构下已存在的合同编号（`contractNo`）；
   - 某配额行已用次数大于 0（`usedCount > 0`）的合同，用于验证编辑时“行配额不能小于已用次数”。
