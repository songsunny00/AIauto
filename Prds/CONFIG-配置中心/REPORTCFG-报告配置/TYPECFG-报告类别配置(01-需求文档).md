## 1. 项目概述

### 1.1 项目背景

配置中心现有“报告配置”页面主要用于管理报告模板、报告命名规则和报告周期，但缺少面向 WGS/WES 项目的报告类别统一配置入口。当前系统中，WGS/WES 项目对应的项目编码为 `XOME`。业务侧希望能够按产品套餐维度维护不同位点类型下可选的“报告类别”，以减少解读侧依赖固定枚举带来的维护成本。

最初版需求提出该功能面向 WGS/WES 检测项目使用；结合当前前端最终实现，该功能入口挂载在项目编码 `XOME` 下，对应的项目展示名称为“WGS/WES”。

### 1.2 项目定位

“报告类别配置”是配置中心下的一个新增配置能力，用于让具备报告配置菜单权限的用户，在报告配置页面中按产品套餐维护 WGS/WES 项目各位点类型可选的报告类别组合。

### 1.3 本期范围与不做事项

- 本期包含：
  - 在“报告配置”页面增加“报告类别配置”入口。
  - 仅在 WGS/WES 项目下展示该入口；该项目在系统中的项目编码为 `XOME`。
  - 打开弹窗后展示项目、产品套餐、位点类型 Tab 和对应报告类别复选项。
  - 支持读取当前产品套餐已保存配置。
  - 支持保存当前产品套餐的报告类别配置。
- 本期不做：
  - 不支持 WGS/WES 之外项目的入口展示与配置保存。
  - 不支持在同一次提交中批量保存多个产品套餐配置。
  - 不支持自定义新增/删除位点类型。
  - 不支持自定义新增报告类别枚举值。
  - 不支持配置排序、版本历史、变更审计与回滚。
  - 不在本功能内验证下游解读页面的实际生效表现。

## 4. 主业务流程

### 4.1 主流程 F01：维护产品套餐报告类别配置

1. 用户进入“配置中心 / 报告配置”页面。
2. 页面默认带出当前用户的默认项目，并完成报告配置页基础查询。
3. 当当前项目为 WGS/WES（项目编码 `XOME`）时，页面操作区显示“报告类别配置”按钮。
4. 用户点击“报告类别配置”按钮，系统打开配置弹窗。
5. 系统展示当前项目名称，并查询该项目下可用的产品套餐列表。
6. 系统默认选中第一个可用产品套餐，并读取其已保存的报告类别配置。
7. 用户在不同位点类型下勾选或取消勾选报告类别。
8. 用户点击“确定”保存当前正在配置的产品套餐内容。
9. 保存成功后，系统提示成功、关闭弹窗并清空本次临时编辑内容。

##### 功能说明

用户在“报告配置”页面完成项目切换或默认项目加载后，当当前项目为 WGS/WES（项目编码 `XOME`）时，可在页面操作区看到“报告类别配置”按钮。点击该按钮后打开报告类别配置弹窗。

##### 页面展示说明

- 入口位于“报告配置”页面操作区，与“下载模板”“报告命名”“报告周期”等操作并列。

- 页面初始化时默认带出当前用户的默认项目。
- 用户切换项目后，页面重新执行查询；入口显隐随当前项目变化。

#### REQ-CONFIG-REPORTCFG-TYPECFG-002 产品套餐加载与配置回填

##### 版本与状态

| 项           | 内容                               |
| ------------ | ---------------------------------- |
| 功能点编号   | `REQ-CONFIG-REPORTCFG-TYPECFG-002` |
| 需求类型     | 新增                               |
| 引入版本     | `V1.5.3.1`                         |
| 最近变更版本 | `V1.5.3.1`                         |
| 当前状态     | 已实现                             |
| 关联验收编号 | `A02`                              |

##### 功能说明

弹窗打开后，系统需要展示当前项目并提供产品套餐下拉列表。用户可切换不同产品套餐查看其已保存的报告类别配置。

##### 业务规则

- 产品套餐列表通过接口按项目获取。
- 仅展示处于启用状态的产品套餐。
- 弹窗首次打开后默认选中第一个可用产品套餐。
- 同一次配置过程中，同一产品套餐仅自动读取一次已保存配置；再次切回时直接使用当前会话中的临时编辑结果。
- 查询返回的配置结果仅回显当前规则允许配置的报告类别，不再适用的历史选项不回显。

##### 交互逻辑

- 打开弹窗后先加载产品套餐列表，再以首个产品套餐为默认值查询配置。弹窗每次打开均重新请求产品列表。
- 用户切换产品套餐时，如该产品尚未在本次会话中读取过配置，则发起配置查询；若再次切回已读取过配置的产品套餐，则直接使用当前会话中的临时编辑结果。
- 查询成功时，系统回填当前产品套餐在各位点类型下已保存的报告类别配置；查询失败时保留空配置并提示，用户仍可手工勾选并保存。

##### 交互路径图

```

    ├─ 失败

    └─ 成功

        │       │
        │       ▼

        │       │
        │       ▼

        │       │ 成功
        │       ▼
        │  [已回填，可编辑]
        │       │
        │       └── 用户切换产品套餐（重复配置回填流程）
        │
        └─ 列表为空
                ▼
           [无可用产品] 产品下拉框显示“暂无可用数据”并禁用，位点类型区域正常展示但不可操作，确定按钮禁用
```

##### 异常场景

- **产品列表为空**：产品下拉框显示"暂无可用数据"并禁用；位点类型区域正常展示但不可操作；确定按钮禁用，用户只能关闭弹窗。
- **产品列表接口失败**：弹窗内显示错误提示；位点类型区域正常展示但不可操作；确定按钮禁用；弹窗保持打开，用户可关闭弹窗。
- **配置查询失败**：当前产品以空配置展示，Toast 提示失败；用户仍可手工勾选并保存。

##### 页面展示说明

- 弹窗顶部展示当前项目和产品套餐选择框。
- 打开弹窗后，先加载当前项目下可配置的产品套餐列表。
- 当存在可用产品套餐时，默认选中第一个产品套餐并回填已保存配置。
- 当产品列表为空时，产品下拉框显示“暂无可用数据”；位点类型区域仍正常展示，但不可操作。
- 当产品列表加载失败时，弹出错误提示；位点类型区域仍正常展示，但不可操作。

##### 业务状态

| 状态中文   | 状态编码   | 含义                                         |
| ---------- | ---------- | -------------------------------------------- |
| 待加载     | 待加载     | 弹窗刚打开，尚未获取产品列表                 |
| 无可用产品 | 无可用产品 | 产品列表为空，确定按钮禁用                   |
| 加载失败   | 加载失败   | 产品列表接口失败，确定按钮禁用，弹窗保持打开 |
| 已加载     | 已加载     | 产品列表已获取，并已回填当前产品配置         |
| 查询失败   | 查询失败   | 配置读取失败，保留空配置可继续编辑           |

##### 已知约束

- 当前版本不做弹窗打开期间的产品状态实时同步（无 polling/WebSocket）。若会话期间产品被后台禁用，保存接口失败时由统一错误处理提示；下次打开弹窗时将获取最新列表。
- 单次保存仅提交当前激活产品套餐；弹窗关闭后所有会话内临时编辑状态清空。

#### REQ-CONFIG-REPORTCFG-TYPECFG-003 位点类型报告类别勾选

##### 版本与状态

| 项           | 内容                               |
| ------------ | ---------------------------------- |
| 功能点编号   | `REQ-CONFIG-REPORTCFG-TYPECFG-003` |
| 需求类型     | 新增                               |
| 引入版本     | `V1.5.3.1`                         |
| 最近变更版本 | `V1.5.3.1`                         |
| 当前状态     | 已实现                             |
| 关联验收编号 | `A03`                              |

##### 功能说明

用户在弹窗中按位点类型查看和勾选当前产品套餐允许使用的报告类别。每个位点类型独立维护自己的勾选结果，并实时显示当前已选择数量。

> 引入路径：配置中心 / 报告配置 / 报告类别配置弹窗 / 位点类型 Tab 区域
>
> 原型对应：见 4.2.2 报告类别配置弹窗示意中的 Tab 切换与报告类别复选区。

##### 业务规则

- 当前实现包含 7 个位点类型：`SNV/ExonCNV`、`LargeCNV`、`LOH`、`MT`、`STR`、`地贫CNV`、`SV`。
- 各位点类型允许勾选的报告类别集合固定，不支持用户自定义新增选项。
- 每个位点类型的勾选结果独立保存。
- 已选择数量随当前位点类型的勾选变化实时统计展示。
- 当前需求未要求每个位点类型至少选择 1 项，因此允许暂不勾选任何报告类别。

##### 交互逻辑

- 弹窗中部使用位点类型 Tab 展示不同配置分组。
- 用户点击不同位点类型进行切换时，只展示当前位点类型对应的报告类别复选项。
- 用户可勾选多个报告类别，界面同步展示当前位点类型下已选择的数量。
- 当前位点类型中的勾选变化会立即写入当前产品套餐的临时编辑结果，各位点类型的勾选结果独立保存。
- 当前需求允许某个位点类型不勾选任何报告类别。
- 关闭弹窗后，未保存的勾选结果不会保留。

##### 全选/取消全选

每个位点类型 Tab 面板顶部提供"全选"复选框，与已选数量并排展示。点击后一键全选或取消全选当前位点类型下所有报告类别，各选项勾选状态实时联动。全部已选时呈全选态，部分已选时呈半选（indeterminate）态，全部未选时呈未选态。全选操作仅作用于当前位点类型，不影响其他位点类型。全选复选框与各选项遵循相同的禁用条件。

#### REQ-CONFIG-REPORTCFG-TYPECFG-004 当前产品配置保存

##### 版本与状态

| 项           | 内容                               |
| ------------ | ---------------------------------- |
| 功能点编号   | `REQ-CONFIG-REPORTCFG-TYPECFG-004` |
| 需求类型     | 新增                               |
| 引入版本     | `V1.5.3.1`                         |
| 最近变更版本 | `V1.5.3.1`                         |
| 当前状态     | 已实现                             |
| 关联验收编号 | `A04`                              |

##### 功能说明

用户完成当前产品套餐的报告类别勾选后，可提交保存。系统仅提交当前正在配置的产品套餐内容，不提交其他产品套餐的未保存修改。

##### 业务规则

- 保存前必须已选定当前产品套餐。
- 提交内容包括当前产品套餐及其对应的报告类别配置结果。
- 报告类别配置结果覆盖当前产品套餐下全部位点类型。
- 保存成功后关闭弹窗并重置本地状态。
- 保存失败时由统一错误处理提示，弹窗保持打开。

##### 交互逻辑

- 用户点击“确定”触发保存。
- 保存中禁用取消按钮与重复提交按钮。
- 保存成功后提示成功并关闭弹窗。
- 用户点击关闭或取消时，不触发保存，直接丢弃本次临时编辑内容。

##### 提交内容说明

- 保存时仅提交当前正在配置的产品套餐。
- 提交内容包含该产品套餐在各位点类型下的报告类别勾选结果。
- 例如：SNV/ExonCNV 可选择“主要、次要、ACMG”，LargeCNV 可选择“正式”，LOH 可选择“附加”。

##### 业务状态

| 状态中文 | 状态编码 | 含义                     |
| -------- | -------- | ------------------------ |
| 保存中   | 保存中   | 已发起保存请求，等待结果 |
| 保存成功 | 保存成功 | 服务端已接收并成功保存   |
| 保存失败 | 保存失败 | 服务端保存失败或网络异常 |
