## 1. 引言

### 1.1 编写目的

本文档为"配置中心-报告配置-报告类别配置"功能的详细设计说明，用于向前端、后端、测试说明该功能在当前仓库中的落地方式、接口依赖、字段契约与交互状态，作为联调与测试的重要依据。

面向对象：前端开发工程师、后端开发工程师、测试工程师、产品经理。

### 1.2 项目背景

"报告类别配置"是在现有"报告配置"页面上新增的一项配置能力。业务上需要按产品套餐维护不同位点类型下的报告类别枚举集合，避免依赖固定配置。当前最终实现将该能力挂载于 `XOME` 项目场景下，其中 `XOME` 是项目编码，对应的项目展示名称为"WGS/WES"，并通过独立弹窗完成产品套餐切换、配置读取与保存。

### 1.3 定义与缩略语

| 术语/缩略语       | 说明                                                                  |
| ----------------- | --------------------------------------------------------------------- |
| XOME              | 当前前端实现中承载本功能入口的项目编码，对应的项目展示名称为"WGS/WES" |
| WGS/WES           | `XOME` 项目编码对应的项目展示名称                                     |
| 报告配置          | 配置中心中的页面模块，对应路由 `/config/reportConfig`                 |
| 报告类别配置      | 本次新增功能，对应"报告配置"页面中的配置弹窗                          |
| productNo         | 产品套餐编码                                                          |
| reportTypeConfigs | 某一产品套餐在各位点类型下的报告类别配置对象                          |
| ExonCNVAndSNV     | SNV/ExonCNV 位点类型的配置键                                          |

###### 4. 处理逻辑

> 本流程图合并自需求文档 4.2 交互路径图，补充了中间状态分支。

1. 弹窗打开后自动触发，进入「待加载」状态
   ↓
2. 前端调用 `GET /base/products/queryForReportTemplate/{projectCode}` 查询产品套餐列表
   ├─ 加载中：展示 loading
   ├─ 加载失败：进入「加载失败」状态，显示错误提示，Tab 区域不可操作，确定按钮禁用，弹窗保持打开
   └─ 加载成功：前端过滤 `status=1` 的产品套餐
      ├─ 列表为空：进入「无可用产品」状态，下拉禁用显示"暂无可用数据"，Tab 区域不可操作，确定按钮禁用
      └─ 列表非空：默认选中首个产品，进入步骤 3
   ↓
3. 前端调用 `GET /base/products/reportTypeConfigs/{productNo}` 查询当前产品配置
   ├─ 回填中：展示 loading
   ├─ 回填失败：进入「查询失败」状态，提示查询错误，保留空配置，仍可编辑
   └─ 回填成功：进入「已加载」状态，回填 `result.reportTypeConfigs`，过滤非法枚举值
   ↓
4. 用户切换产品套餐时
   ├─ 已加载产品：直接使用本地草稿，不重复查询
   └─ 未加载产品：重复步骤 3，快速连续切换时以最后一次结果为准（忽略前序请求结果）

**业务状态枚举**：

| 状态中文 | 状态编码 | 含义 | UI 表现 |
| --- | --- | --- | --- |
| 待加载 | 待加载 | 弹窗刚打开，尚未获取产品列表 | loading |
| 无可用产品 | 无可用产品 | 产品列表为空 | 下拉禁用，Tab 不可操作，确定禁用 |
| 加载失败 | 加载失败 | 产品列表接口失败 | 错误提示，Tab 不可操作，确定禁用，弹窗保持打开 |
| 已加载 | 已加载 | 产品列表已获取，并已回填当前产品配置 | 正常可编辑 |
| 查询失败 | 查询失败 | 配置读取失败 | 保留空配置，提示查询失败，仍可编辑 |
