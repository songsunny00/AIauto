# 项目级追踪总览

## 1. 使用说明

本文件用于汇总模块级 `TRACE.yaml` 的关键信息，形成项目级追踪视图。

建议使用场景：

- 阶段评审
- 回归状态总览
- 版本关闭前检查
- 领导/治理角色快速查看当前推进状态

## 2. 汇总规则

- 模块责任人维护各自模块叶子目录下的 `TRACE.yaml`
- 治理角色按固定节奏汇总到本文件
- 本文件只做项目级总览，不替代模块级 `TRACE.yaml`
