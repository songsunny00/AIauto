标题：AI 赋能：需求开发到自动化测试的一体化实践

内容摘要：以功能点编号（REQ）贯穿需求—开发—测试全流程，实现可追踪、可回填的一体化协同。基于 Playwright(UI) + Playwright(API) 同栈的自动化测试体系，由 REQ 派生 FT/IT/ATS 编号统一追溯链路，AI 承担脚本骨架生成、失败归因与结果回填等辅助角色，配合失败六分类与缺陷闭环，实现高效可控、可复制可审计的自动化测试落地。

分享人介绍：宋焕莲，2019 年加入华大基因，现任 BIT 技术研发部软件工程组软件开发工程师，目前主要负责OmicsOne、halos等系统开发，同时承担了系统架构优化、团队AI落地实践等工作
